# 一键安装包(项目依赖打包成 EXE)

把这套系统**所有 Python 依赖**打包成一个自解压 EXE。换机器或重装时双击一次,
**不用再下载、不用编译**。

工具链含 frida / playwright / capstone / keystone / pyelftools / cryptography / python-docx 等;
换脸环境含 opencv、onnx、**onnxruntime-gpu 1.26**、insightface 0.7.3、PySide6、keras、scipy、scikit-image。

## 怎么用

**双击 EXE** → 确认提示(会说明要写入 `D:\zhibo`)→ 自动完成:

1. 校验解压结果
2. 修复虚拟环境路径(重写 `pyvenv.cfg` 指向新 py312)
3. 安装中控台到 `E:\zhibo\console`
4. 把 Python 加入当前用户 PATH(并清掉 `3.14` 和旧 `D:\py312` 残留条目)
5. **自检**:打印 Python 版本 + 验证换脸环境

装完**新开一个终端**,PATH 才生效。

## 技术说明(为什么这么做)

- **打包"装好的环境"而不是 whl 轮子**:安装时 pip 缓存里已没有轮子,重新下载约 1.2 GB,
  而且本机网络不稳(清华镜像上有个 231130 字节的文件**固定损坏**,`IncompleteRead` 的字节数
  每次完全一样,换阿里源才绕过)。直接打包已验证可用的环境 —— 安装时零下载、零编译。
- **零拷贝打包**:7za 直接从 `D:\zhibo` 相对路径打包 `runtime\py312`、
  `runtime\DeepLiveCam\.venv`、`_setup`,**不先复制 2.2GB 到暂存目录**,省一半时间和磁盘。
- **解压即到位**:SFX 的 `InstallPath=D:\zhibo`,包内结构就是最终结构,不需要安装后再搬。
- **venv 是路径绑定的**:所以固定落到 `D:\zhibo\runtime\DeepLiveCam\.venv`,
  并由 `install.bat` 重写 `pyvenv.cfg`。**换根目录会失效**。
- 用 `7zSD.sfx` + LZMA2(`-mx=5 -mmt=on`)构建。

## 重建命令

构建工具已随项目保留:

| 文件 | 用途 |
|---|---|
| `D:\zhibo\tools\7za.exe` | 压缩器 |
| `D:\zhibo\tools\7zSD.sfx` | 自解压安装器模块 |
| `D:\zhibo\tools\sfx_config.txt` | SFX 配置(标题/提示/解压路径/自动运行) |

```powershell
# 1. 准备 _setup（安装脚本 + 中控台 + python 安装包）
New-Item -ItemType Directory -Force D:\zhibo\_setup | Out-Null
robocopy E:\zhibo\console D:\zhibo\_setup\console /E
# install.bat 与 add_to_path.py 见本文件历史版本或仓库记录

# 2. 打包（从 D:\zhibo 相对路径，避免复制大文件）
cd D:\zhibo
.\tools\7za.exe a -t7z -mx=5 -mmt=on dist\payload.7z runtime\py312 runtime\DeepLiveCam\.venv _setup

# 3. 合成 EXE
cmd /c 'copy /b "D:\zhibo\tools\7zSD.sfx" + "D:\zhibo\tools\sfx_config.txt" + "D:\zhibo\dist\payload.7z" "D:\zhibo\dist\直播系统依赖_一键安装.exe"'

# 4. 校验后清理
.\tools\7za.exe t dist\直播系统依赖_一键安装.exe
Remove-Item dist\payload.7z, _setup -Recurse -Force
```

> 旧版本安装包(写的是搬迁前的 `D:\py312`、`D:\DeepLiveCam` 路径)如果还留在
> `D:\备份\pythone\`,**已经过期,可以删掉**,用本目录这个新的。
