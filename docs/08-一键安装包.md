**双击 `直播系统依赖_一键安装.exe`** → 确认提示 → 自动完成:

1. 校验解压结果
2. 修复虚拟环境路径(重写 `pyvenv.cfg`)
3. 安装中控台到 `E:\zhibo\console`

## 技术说明(为什么这么做)

- **为什么打包"装好的环境"而不是 whl 轮子**:安装时 pip 缓存里已没有轮子,重新下载约 1.2 GB,而且本机网络不稳(清华镜像上有个 231130 字节的文件**固定损坏**,`IncompleteRead` 的字节数每次完全一样,换阿里源才绕过)。直接打包已验证可用的环境,安装时零下载、零编译。
- **零拷贝解压**:安装包内部结构就是 `py312\` 和 `DeepLiveCam\.venv\`,SFX 直接解压到 `D:\`,不走"先解压到临时目录再复制"那一套,省一半时间和磁盘。
- **venv 是路径绑定的**:所以固定落到 `D:\zhibo\runtime\DeepLiveCam\.venv`,并由 `install.bat` 重写 `pyvenv.cfg`。换路径的话 venv 会失效。
- 用 `7zSD.sfx` + LZMA2(`-mx=5 -mmt=on`)构建,已通过 **CRC 全量校验**(`Everything is Ok`)。
