# 没有麦克风/摄像头,怎么把系统跑完整

## 本机的硬件与系统现实(实测)

| 项 | 实际情况 |
|---|---|
| 麦克风 | ❌ 没有任何采集设备 |
| 摄像头 | ❌ 没有任何 Camera 设备 |
| 系统 | **Windows 10 企业版 N LTSC** —— N 版**不含媒体和语音组件** |
| 系统 TTS | ❌ 不可用(`System.Speech` 的 COM 类未注册,`0x80040154`) |
| 音频服务 | ✅ Audiosrv / AudioEndpointBuilder 都在运行 |

所以"真人对着麦克风实时讲"这条路**现在跑不了**。但整套系统并不依赖它才能完整。

## 解法:把"实时设备"换成"文件 + 在线服务"

```
            【原本需要麦克风】                   【现在的替代方案】
话术 ──► 真人对麦克风念 ──► RVC实时变声     话术 ──► edge-tts 合成 ──► RVC 转音色 ──► wav
            【原本需要摄像头】                   【现在的替代方案】
         摄像头实时画面 ──► 实时换脸          预制视频文件 ──► 换脸(文件模式) ──► mp4
```

### ① 文字 → 卖家音色语音 ✅ 已打通并验证

用 **edge-tts**(微软 Edge 的在线神经语音,免费、中文自然、不依赖系统媒体组件)当"声源",
再过已训好的 RVC 模型换成卖家音色。

**中控台里一键用**:生成话术后,点「生成语音」→ 浏览器里直接播放/下载。

命令行用法:
```powershell
& 'D:\py312\python\python.exe' 'e:\zhibo\console\tts_to_voice.py' `
    --text "大家好，今天这款纯棉短袖两件只要六十九，包邮到家。" `
    --out 'D:\voice-data\out\demo.wav'
```

常用参数:

| 参数 | 说明 |
|---|---|
| `--voice` | 声源。`zh-CN-XiaoxiaoNeural`(女·自然)、`zh-CN-XiaoyiNeural`(女·活泼)、`zh-CN-YunjianNeural`(男·解说感)、`zh-CN-YunxiNeural`(男·年轻) |
| `--rate` | 语速,带货可 `+8%` ~ `+25%` |
| `--pitch` | RVC 变调半音。**先用 0 试**;女声TTS配男声模型可试 `-12`~`-6` |
| `--keep-tts` | 保留中间的 TTS 原声,方便和换音色后的对比 |

实测产出:32kHz / 单声道 / 16bit 的 wav,时长与文本匹配。

> 调音色相似度:`--pitch`(音高)最关键,其次是 `--index-rate`(默认 0.75,越高越贴近训练音色)。
> 换不同 `--voice` 会影响语气节奏 —— 音色由 RVC 决定,**节奏由 TTS 决定**。

### ② 换脸 → 用视频文件(不需要摄像头)

Deep-Live-Cam 支持文件模式:

```powershell
& 'D:\DeepLiveCam\.venv\Scripts\python.exe' 'D:\DeepLiveCam\run.py' `
    -s 卖家正脸照.jpg -t 素材视频.mp4 -o 输出.mp4 --execution-provider cuda
```

实测该环境 **CUDA 可用**(`accelerator: CUDA (NVIDIA)`),1050Ti 能跑。

### ③ 这样其实已经可以开播了(录播路线)

完全不需要麦克风和摄像头的闭环:

1. 中控台生成**讲解话术 + 问答库**
2. 一键把话术变成**卖家音色音频**(上面①)
3. 准备画面:预制视频(可选过②换脸)
4. **OBS 用「媒体源」**加载视频 + 音频 → 推流抖音(标注 AI)
5. 真人中控**只用键盘**盯评论:观众提问 → 点问答库「念这条」/ 生成回应 → 用①合成语音播出去

这正是方案里"**录播 + 真人兜底**"的那条路,全程零硬件。

## 什么时候才真的需要补硬件

| 能力 | 需要什么 | 说明 |
|---|---|---|
| **真人实时讲 + 实时变声** | 麦克风 + VB-CABLE | 这是"实时接管"的核心,想做到观众提问即时口头回应就必须有 |
| **真人实时出镜 + 实时换脸** | 摄像头 | 手机也行(DroidCam / iVCam 把手机变成摄像头) |
| 把播出画面喂给换脸工具 | OBS 虚拟摄像头 | 装 OBS 虚拟摄像头驱动(需管理员),可用视频文件冒充摄像头 |

一支几十块的 USB 麦克风 + 一个 USB 摄像头(或直接用手机)就能补齐。
**在补齐之前,上面①②③ 已经能把系统跑完整、能出片、能开播。**

## 为什么不用系统自带 TTS

系统是 N 版,语音组件被移除,`System.Speech` 直接报 `REGDB_E_CLASSNOTREG`。
装 Media Feature Pack 也不保证恢复中文语音库,所以直接用 edge-tts —— 免费、音质更好、还不占本地算力。
