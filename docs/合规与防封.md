# 合规与防封

## 深度合成三条红线（国内）

1. **非真人要告知** —— 内容涉及 AI 合成，要让观众可感知。
2. **禁止冒充特定真人** —— 核心红线。换脸换声去冒充**别人**、无授权 = 侵犯肖像权/声音权。
3. **必须加深度合成标识** —— 直播间标注"AI"/"数字人"。

## 为什么本项目合规

用**卖家本人**的脸、**本人**的声、给**本人**的货带货 —— 本人授权，不涉及冒充他人。
对外**标注 AI** 即可，红线不踩。

## 防限流 / 防封要点

- 画面别长时间"静止循环感"：真人实时驱动天然有变化，这点本项目有优势。
- 标注合规，别伪装成"纯人工直播"规避检测。
- 价格/秒杀等**易变信息**用真人口播或屏幕浮层字幕补，别做死进素材。
- 真人中控全程盯评论、兜底互动。
