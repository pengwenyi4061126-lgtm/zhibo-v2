# AI 中控台(话术提词 + 评论区助手)

直播时你(或助理)面前的那块"大脑"。零依赖:只用 Python 标准库,不需要装任何包。

## 启动

```powershell
& 'D:\py312\python\python.exe' 'e:\zhibo\console\server.py'
```
或双击 `启动中控台.bat`。

| 页面 | 地址 | 用途 |
|---|---|---|
| 中控台 | http://127.0.0.1:8777 | 你操作的主界面 |
| 提词器 | http://127.0.0.1:8777/teleprompter | 念稿用;也可作 OBS 浏览器源 |

## 先配密钥(必须)

话术生成走 DeepSeek。打开 `e:\zhibo\.env`,把 key 填在等号后:

```
DEEPSEEK_API_KEY=sk-你的新密钥
```

> ⚠️ 机器环境变量里有个旧 key(`sk-b06...aa01`)**已失效**(实测返回 401)。
> 去 <https://platform.deepseek.com> 新建一个。`.env` 里填的会**覆盖**那个旧的。
> `.env` 已被 git 忽略,不会提交。

中控台右上角会显示「DeepSeek 已配置」或红色未配置提示。

## 三个功能

### 1. 话术(提词)
左栏填商品名 + 卖点/规格/价格 → 点「生成讲解话术」。
生成后**自动推送到提词器**;可以直接在文本框里改,再点「推送到提词器」。

### 2. 问答库
点「生成问答库」出 12 条常见问答(价格、尺码、材质、发货、售后…)。
观众一问,点那条的「念这条」→ 立刻出现在提词器上。**这是半无人直播接得住问题的关键。**

### 3. 评论区助手
把观众弹幕粘进去 → 「生成回应」→ 得到一句能直接念的口语回答 → 可推到提词器。

### 4. 生成卖家音色语音(不需要麦克风)
话术生成后点「生成语音」:**edge-tts 合成 → RVC 换成卖家音色** → 浏览器里直接播放/下载。

| 选项 | 说明 |
|---|---|
| 声源 | 晓晓(女·自然)/ 晓伊(女·活泼)/ 云健(男·解说感)/ 云希(男·年轻) |
| 语速 | 带货一般 +8% ~ +15% |
| 变调 | **先用 0**;女声声源配男声模型可试 -12 ~ -6 |

音色由 RVC 模型决定,**语气节奏由声源决定**。产物在 `D:\voice-data\out\`。
原理和命令行用法见 [`09-没有麦克风和摄像头怎么办.md`](09-没有麦克风和摄像头怎么办.md)。

## 提词器操作

- **空格键** = 开始/暂停滚动(直播时最常用)
- 滑杆调速度和字号;「⤒ 回顶」重新开始
- 蓝色细线是视线参考位

### 作为 OBS 浏览器源(叠在画面上)

地址加参数:
```
http://127.0.0.1:8777/teleprompter?bg=0&bar=0
```
- `bg=0` 背景透明(能叠在摄像头画面上)
- `bar=0` 隐藏底部控制条(观众看不到按钮)

> 提词器一般只给主播自己看(放第二个显示器/另开窗口),**不要**加进推流画面。
> 加进 OBS 只在你想把它做成"只在预览里可见"的场景时用。

## 合规内置

话术生成的系统提示里已经硬性约束:

- 不用绝对化用语(最好/第一/最便宜/国家级/永久/万能)
- 不做医疗功效、治疗、减肥承诺
- 不编造销量和权威认证、不贬低同行、不承诺收益
- 不确定的信息统一说「以商品详情页为准」

左栏底部还有开播前的合规检查清单。
