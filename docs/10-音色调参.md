# 音色调参(用测量代替猜)

第一版合成出来"不像、没感染力"。靠耳朵来回试很慢,所以先把卖家真声**量化**,再照着指标调。

## 卖家真声画像(40 段训练素材实测)

| 指标 | 数值 | 意义 |
|---|---|---|
| F0 中位数 | **201.2 Hz** | 整体音高(段间 166~292) |
| F0 高位 p90 | **277.8 Hz** | 情绪高涨时的音高 = 听感上的"尖锐" |
| F0 低位 p10 | 147.2 Hz | |
| **音高起伏** | **11.0 半音** | **感染力的关键指标** |
| 音量 | **-17.4 dB** | |

## 第一版为什么不像

| 问题 | 数据 | 原因 |
|---|---|---|
| 听着尖 | 输出 265.8 Hz vs 卖家中位 201.2 | 把卖家**情绪最高点**的音高全程铺满了 |
| 没感染力 | 起伏只有 6~7 半音 vs 真人 11.0 | 声源选错(晓伊/云健起伏小) |
| 发虚没劲 | -22.7 dB vs 真人 -17.4 | RVC 输出比真人素材轻 4~5 dB |

> 注意:一开始我用 25 段算出中位 199 Hz,就断定"要降 5 个半音"。但卖家**单段能到 248~292 Hz**,
> 所以用户说"尖、音调高"是对的 —— **单一中位数会骗人,要同时看 p90 和起伏**。

## 结论:三个参数各管一件事

| 要解决 | 调什么 | 实测结论 |
|---|---|---|
| 音高像不像 | `--pitch` | 晓晓声源:`-4`→202Hz、`-3`→216Hz、`-2`→~230Hz、`-1`→245Hz |
| **有没有感染力** | `--voice` + `--rms-mix-rate` | **必须用晓晓**(起伏 10.8 半音);晓伊只有 6.3 → 平。`rms-mix-rate 0.25` |
| 够不够响 | `--target-rms-db` | 设 `-17.4`,输出自动归一化到真人音量 |

## ★ 定版配方(F4,已写进代码默认值)

```
--voice zh-CN-XiaoxiaoNeural  --pitch -1  --rate +10%  --volume +15%
--index-rate 0.90  --rms-mix-rate 0.25  --target-rms-db -17.4
```

实测 **F0 245.2Hz / 起伏 10.6 半音 / 音量 -17.5 dB**。

### 为什么选 245Hz 而不是"统计最准"的 202Hz

试听后定的是 F4(245Hz),不是综合打分最高的 F1(202Hz)。这不矛盾:

- 训练素材的**整体中位数 201Hz** 掺了大量平静/低语段落
- 但卖家**带货讲解时用的是高音区**(p90 = **277.8Hz**)
- 所以对齐"整体中位"会显得偏闷,对齐"高音区"才像他在卖货

**教训:选目标值要看使用场景的那个音域,不是全样本中位数。** 耳朵在这件事上比单一统计量可靠。

> 复测提示:同一套参数换一句话重跑,F0 中位会有 ±0.5~1 个半音的浮动(实测另一句话出 253.8Hz),
> 这是**文本韵律差异**造成的正常波动,不是参数跑偏。判断参数对不对要看多句平均,别用单句卡死。

## 还想更像的话

1. **index-rate 调到 0.95~1.0** —— 更贴训练音色,但过高会有金属感
2. **protect 降到 0.2** —— 清辅音更贴,代价是可能出电音
3. **加数据重训** —— 现在只有 14.4 分钟。加到 30 分钟以上,音色稳定度会明显提升
4. **语气的天花板在 TTS**:RVC 只换音色,**节奏和情绪来自声源**。想要真正的带货爆发力,
   最终还是真人口播(或用原素材音频)最自然 —— 这也是方案里"录播为主"的原因。
