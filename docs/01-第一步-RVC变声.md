# 第一步：RVC 变声验证

> 整条路最该先验证的一环。**变声像了、延迟可接受，其余都是搭积木；不像，就得先调这。**

## 现成素材（不用重新采集）

- 切好的人声数据：`D:\voice-data\sliced`
- 源视频（需要补数据时）：`D:\voice-data\球.spxzq.mp4`

## 步骤

1. **装 RVC 训练环境**
   - 拉 RVC 整合包（WebUI 版即可，含训练 + 推理）。
   - 它对数据要求比 GPT-SoVITS 还低，`sliced` 那份直接够用。

2. **训练卖家音色模型**
   - 数据集指向 `D:\voice-data\sliced`。
   - 常规参数先跑一版（采样率 40k/48k、特征提取 RMVPE）。
   - 产出 `.pth` 模型 + `.index` 特征索引。

3. **装 w-okada 实时变声客户端**
   - 加载上一步的 `.pth` + `.index`。
   - 输入选麦克风，输出选虚拟声卡 / OBS 音频源。

4. **测两件事**
   - **像不像**：对着麦说话，听转出来的音色是否贴近卖家本人。
   - **延迟**：实时讲话到输出的延迟是否可接受（直播能用）。

## 判据

| 结果 | 下一步 |
|---|---|
| 像 + 延迟可接受 ✅ | 进阶段二（Deep-Live-Cam 换脸 + OBS） |
| 不够像 | 加数据 / 调训练轮数 / 换特征算法重训 |
| 延迟大 | 调 w-okada 缓冲块、换更快的推理设置 |

## 备注

- 模型 `.pth` / `.index` 较大，已在 `.gitignore` 里忽略；建议统一放 `D:\voice-data\models\`。
- RVC 走的是"实时转音色"，和旧的 GPT-SoVITS（文字转语音）是两条路；`sliced` 数据两者通用，没白切。
