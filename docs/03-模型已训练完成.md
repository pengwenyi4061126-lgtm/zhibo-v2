## 云端踩过的坑(已全部解决,留档备查)

1. **数据集识别**:Kaggle 会自动解包上传的 zip,所以要找 `*.wav` 而不是 `*.zip`。
2. **缺 ffmpeg**:`infer/audio.py` 导入的是 `ffmpeg-python` 包,且需要 ffmpeg 可执行程序(apt 装)。
3. **最关键 —— 模块导入冲突**:必须用 `python -m train.preprocess` 这种**模块方式**运行。
   用 `python train/preprocess.py` 会把 `train/` 放到 sys.path 首位,导致 `import train`
   命中 `train/train.py` 文件而不是包,报 `cannot import name 'utils' from 'train'`。
4. **v2 不支持 40k**:`configs/v2/` 只有 32k 和 48k 模板。我们用 32k(正好匹配素材)。
5. **输出瘦身**:仓库和 600MB 资产放 `/tmp`,只把成品拷进 `/kaggle/working`,否则下载极慢。
