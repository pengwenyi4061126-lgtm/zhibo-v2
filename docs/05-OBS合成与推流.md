# OBS 合成与推流抖音

OBS 是整套系统的"总装车间":把摄像头(换脸后)+ 变声后的音频 + 字幕/空镜拼成一路直播画面,再推给抖音。

| 项 | 位置 |

便携模式已开启(`D:\zhibo\runtime\OBS\portable_mode.txt`),所有配置都存在 `D:\zhibo\runtime\OBS` 里,不写系统目录。
建议发个桌面快捷方式到那个 exe。

## 还缺的两样(需要你补)

| 缺什么 | 为什么要 | 怎么办 |
|---|---|---|
| **摄像头** | 实测本机**没检测到任何摄像头**。换脸要有真人画面输入 | 插个 USB 摄像头;或用手机当摄像头(DroidCam / iVCam);测试阶段也可用视频文件代替 |
| **虚拟声卡 VB-CABLE** | 把 RVC 变声后的声音送进 OBS | 装 [VB-CABLE](https://vb-audio.com/Cable/)(要管理员权限,装完**重启**) |

## 音频链路(关键,别接错)

```
你的麦克风
   ↓
RVC 实时变声 GUI (go-realtime_gui.bat)
   ├─ 输入设备：麦克风
   └─ 输出设备：CABLE Input (VB-Audio Virtual Cable)
          ↓
OBS 添加「音频输入采集」→ 设备选 CABLE Output
          ↓
       推流抖音
```

要点:
- OBS 里**只加 CABLE Output 这一路**。如果同时把麦克风也加进 OBS,观众会听到你的原声和变声两层(破绽)。
- 自己想听监听:在 RVC GUI 里开监听,或 OBS 里对该音频源开「监听并输出」。

## 画面搭建(建议场景结构)

新建场景 `带货主场`,从下往上叠:

| 图层 | OBS 源类型 | 说明 |
|---|---|---|
| 1. 主画面 | 视频采集设备 | 选换脸工具输出的虚拟摄像头(或直接选真摄像头做无换脸测试) |

## 推流抖音两种方式

### 方式 A:直播伴侣抓窗口(最省事,不用推流码)
1. OBS 菜单 → 「全屏投影(预览)」到第二个显示器,或开「窗口投影」。
2. 抖音直播伴侣里添加「窗口采集」,抓这个投影窗口。
3. 用直播伴侣开播。
> 优点:不碰推流码,开播最快。缺点:多一层采集,机器开销略大。

### 方式 B:OBS 直接推流(画质/延迟更好)
1. 在抖音开播页拿到 **推流地址(rtmp://...)** 和 **推流码(串流密钥)**。
2. OBS → 设置 → 推流 → 服务选「自定义」,填服务器和串流密钥。
3. 设置 → 输出:
   - 编码器优先 **NVIDIA NVENC H.264**(你有 1050Ti,硬编不占 CPU)
   - 码率 **4000~6000 Kbps**,关键帧间隔 **2** 秒
4. 设置 → 视频:分辨率 **1080x1920(竖屏)**,帧率 **30**。
5. 点「开始推流」。

> 推流码等同账号凭证,**不要截图外传、不要提交到 git**。

## 1050Ti 性能建议

显卡要同时跑换脸,留点余量:
- 编码用 **NVENC**(别用 x264,会抢 CPU)
- 画面 **1080x1920@30**,别上 60 帧
- 换脸分辨率别拉太高;卡的话降到 720x1280 推流
