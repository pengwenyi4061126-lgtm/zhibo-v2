**代码和环境都在 D:/E 盘,只要不格式化这两个分区就不会丢。** 真正会丢的是 C 盘上的
密钥、令牌和配置 —— 这些已经全部备份到 `D:\zhibo\backup\`。

## 重装后的恢复步骤

1. **恢复 SSH 密钥**
   ```powershell
   New-Item -ItemType Directory -Force "$env:USERPROFILE\.ssh" | Out-Null
   Copy-Item D:\zhibo\backup\ssh\* "$env:USERPROFILE\.ssh\" -Force
   ```
2. **恢复 Kaggle 令牌**(需要云端训练时)
   ```powershell
   New-Item -ItemType Directory -Force "$env:USERPROFILE\.kaggle" | Out-Null
   Copy-Item D:\zhibo\backup\kaggle\* "$env:USERPROFILE\.kaggle\" -Force
   ```
3. **恢复 Kiro 对话历史**(想接着上次的上下文)
   ```powershell
   robocopy D:\zhibo\backup\kiro-sessions "$env:USERPROFILE\.kiro\sessions" /E
   ```
4. **恢复 PATH**:把 Python 加回用户环境变量
   ```
   D:\zhibo\runtime\py312\python\
   D:\zhibo\runtime\py312\python\Scripts\
   ```
   (或直接跑一次 `D:\zhibo\dist\直播系统依赖_一键安装.exe`,它会自动配 PATH 并自检)
5. **装 Git**,然后配仓库用的密钥:
   ```powershell
   git -C E:\zhibo config core.sshCommand "ssh -i C:/Users/<你的用户名>/.ssh/id_ed25519_gh2 -o IdentitiesOnly=yes"
   ```
6. **验证**(三条都应通过):
   ```powershell
   D:\zhibo\runtime\py312\python\python.exe --version
   D:\zhibo\runtime\DeepLiveCam\.venv\Scripts\python.exe -c "import cv2,onnxruntime;print(onnxruntime.get_available_providers())"
   git -C E:\zhibo status -sb
   ```

## ⚠️ 新系统别再装 N 版

当前系统是 **Windows 10 企业版 N LTSC**,N 版**不含媒体和语音组件**,导致系统 TTS 不可用。
换系统时装**普通版(专业版/企业版,非 N)**,能省掉这个坑。
(不过我们的链路用的是 edge-tts,不依赖系统语音,所以装 N 版也能跑。)

## 另外两个硬件建议

既然要重装,顺手补齐这两样,"真人实时接管"那条路才能走通:
- **USB 麦克风**(几十块)—— 实时变声必需
- **摄像头**(或手机装 DroidCam)—— 实时换脸必需
